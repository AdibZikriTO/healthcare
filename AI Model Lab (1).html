AI Model Lab

Compare quality, speed, token usage and cost across AI models. Demo runs on built-in sample data, with no API keys needed.

How it works

Each model has a profile (typical latency, output speed, verbosity, base quality, price per 1M tokens). A test run generates a repeatable simulated answer per question and model, then measures:

  • Speed: time to first token + output tokens ÷ tokens per second.
  • Tokens: input ≈ words × 1.3; output depends on the model's verbosity.
  • Cost: (input × input price + output × output price) ÷ 1,000,000.
  • Quality: a 1–10 sample score. In production, replace it with human ratings or an LLM judge.

To go live, replace callModel() in the page script with a real API request and read the latency and token counts from its response.
